# Callboard WordPress administration

- Mode: Operate.
- Audience: independent artists, labels, and music publishers managing an owned player through WordPress.
- Job: move from activation to a published, presentable first set without learning Callboard's architecture.
- Primary action: add music, finish its presentation, and open the live player.
- Proof: the real library count, live player address, offline state, and existing import paths.
- Constraints: preserve WordPress conventions, capabilities, settings behavior, translation, accessibility, and the no-build cast-facing app.
- Direction: one compact Callboard listening header over a native WordPress setup table.
- Memorable moment: the waveform and dark player surface establish the product, then disappear into familiar WordPress work.
- Set editor: use the classic post editor as a complete music-publishing workflow. Tracks come from the Media Library, remain editable and reorderable in a compact numbered list, and stay in Media when removed from a set.
- Unresolved: a future pass may broaden the Set terminology toward releases or playlists, but the data model and labels remain stable.
