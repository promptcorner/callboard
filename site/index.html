Tech specs

Built on the web.

One WordPress plugin. No app store, no framework, no build step.

Playback

  • HTML media element
  • Media Session
  • Web Audio
  • Audio Session
  • Remote Playback
  • Web Locks
  • Canvas 2D

Offline

  • Service Worker
  • Cache API
  • Range requests
  • Streams
  • Storage

App

  • Web App Manifest
  • Web Share
  • WebKit switch haptics

Interface

  • View Transitions
  • Anchor positioning
  • Container queries
  • text-box-trim
  • text-wrap: pretty
